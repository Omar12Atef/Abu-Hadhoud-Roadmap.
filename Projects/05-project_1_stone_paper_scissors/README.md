## 📌 Overview
A fully interactive console-based **Stone-Paper-Scissors** game implemented in C++.  
This project was developed as **Project 1** within **Course 05: Algorithms & Problem Solving Level 2** in the Abu-Hadhoud Programming Roadmap.

The focus of this project is to apply functional programming, structured data representation, and game-loop architecture to build a complete C++ application.

---

## 🛠️ Key Concepts Applied
- **Structures (`struct`)**: For encapsulating round details (`stRoundInfo`) and total game metrics (`stGameResult`).
- **Enumerations (`enum`)**: For defining explicit game choices and round/game outcomes without using magic numbers.
- **Modular Design**: Breaking down the program into single-responsibility functions (input handling, logic determination, and result presentation).
- **Control Flow**: Utilizing `do-while` loops for repeating game sessions and `for` loops for round progression.
- **Randomization**: Using pseudo-random generation logic (`rand()`, `srand()`) to simulate the computer choice.

---

## 🎮 Game Features
* 🔄 Flexible round selection (1 to 10 rounds per game).
* 📊 Real-time round summaries displaying player vs. computer choices.
* 🏆 Final scorecard tracking total Player Wins, Computer Wins, and Draws.
* 🔁 Instant replay functionality.
