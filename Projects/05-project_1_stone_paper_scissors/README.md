# 🎮 Project 1: Stone, Paper, Scissors Game

## 📌 Description
A C++ console application built as the final project for **Course 05 (Algorithms & Problem Solving Level 2)** in Abu-Hadhoud Roadmap.

## 🛠️ Concepts Applied
- Enums & Structs for structured data management
- Modular Programming (Functions & Separation of Concerns)
- Control Loops (`do-while`, `for`)
- Random Number Generation (`rand()`, `srand()`)

## 🚀 How to Run
1. Copy the code from `main.cpp`.
2. Paste it into any C++ Compiler (VS Code, Visual Studio, or OneCompiler).
3. Build and run!
